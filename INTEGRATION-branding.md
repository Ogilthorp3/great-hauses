# INTEGRATION — branding (app icon + title wordmark)

Shipped 2026-08-09. The mark is **a heater shield party per pale, crimson and
steel, charged with a gold chess king** — the same heater silhouette the
in-game haus sigils use, so the icon is continuous with the product.

Everything below is generated by committed scripts. **The scripts are the
source of truth**; the PNGs are build products. Never retouch a PNG by hand —
change the generator and re-run.

```bash
python3 tools/branding/gen_app_icon.py --out assets/branding --stem app-icon
python3 tools/branding/make_icns.py            # .icns + .ico, from the same script
python3 tools/branding/gen_wordmark.py
```

`tools/branding/gen_app_icon.py` is **byte-identical** to the design original at
`great-houses-assets/branding/concept-a/gen_icon_a.py`. That is what `--out` /
`--stem` exist for: one file, two homes, zero drift. Run it with no arguments in
the design repo and it writes the contact sheet, the 8×/12× nearest-neighbour
zooms and the greyscale proofs used to judge it.

## WIRED ALREADY

**1. `project.godot`** — the editor / project-manager icon:


**2. `src/ui/house_select.gd`** — the Hall of Banners header. `_build_title()`
now hangs a `Wordmark` TextureRect above the screen heading.

Two things in that block are load-bearing and easy to undo by accident:

* `expand_mode = EXPAND_IGNORE_SIZE`. The default (`KEEP_SIZE`) pins the
  control's minimum size to the texture's 1485x176 and runs the wordmark off
  the right edge of the screen.
* `PRESET_TOP_WIDE`, not `PRESET_CENTER_TOP`. `Control.size` grows the right
  offset only, so a centre-anchored TextureRect lands half its own width
  off-centre. Spanning the full width and letting
  `STRETCH_KEEP_ASPECT_CENTERED` do the centring is what actually centres it.
* `mouse_filter = MOUSE_FILTER_IGNORE`, because the node is now full-width and
  the ring's crests are click targets.

The header was re-budgeted at the same time. All numbers are in the **1920x1080
UI space**, not the 1280x720 window — the project stretches `canvas_items`, so
an e2e screenshot is these numbers x0.667, which is exactly the trap that makes
a first attempt look mysteriously undersized. The ring's top crest starts at
`1080*0.5 + 20 - 1080*0.36 - 118*0.5 = 112`, so the header owns y 0..112:

| line | y | size |
|---|---|---|
| `Wordmark` | 4..64 | full-width, aspect-fit |
| `Title` — THE HALL OF BANNERS | 66 | 34pt -> **20pt** |
| `Subtitle` — Nine banners. One throne. | 70 -> **92** | 16pt -> **15pt** |

The heading dropped to 20pt on purpose: brand above screen-name is the right
hierarchy once there IS a brand, and the old 34pt heading plus its subtitle ran
past y=112 and sat behind the top crest. Nothing is occluded now.

The haus-select `Title` label has **no test dependency** — the `Title` that
`test_e2e/e2e_driver.gd:1051` looks up is the HUD one built in
`src/game.gd:1425`. Verified before touching it.

**3. `export_presets.cfg`** — done by another session while this landed; both
`application/icon` fields now point at the new bundle icons. Only
`application/console_wrapper_icon` (Windows preset) is still `""`.

## Design notes worth keeping

* **Detail tiers, not downsamples.** `gen_app_icon.tier_of()` gives every size
  its own drawing: full (≥256), mid (128), mini (64), small (32/16). At 32 the
  knop, bell and collar do not exist — the charge is four flat members on
  whole-pixel boundaries, centred on x = 16.0 exactly. `make_icns.py` renders
  each `.iconset` member natively for the same reason; it never `sips` a 1024
  master down to 16.
* **Two self-checks print PASS/FAIL on every build.** Greyscale split of the two
  tinctures (floor 15 levels, currently 22.5) and outer-rim luminance (floor
  0.12, currently 0.155 at 32px). The second is the regression guard on the
  forged-iron rim: push iron further out and the tile stops having an edge on a
  dark dock.
* **The per-bend diagonal division was tried and rejected** — at 32 the diagonal
  runs into the charge's own silhouette and the steel pools in the bottom-right
  corner, so the heater point reads truncated. Reproduce with
  `python3 tools/branding/gen_app_icon.py --variant perbend` before re-arguing it.
* **No monogram, ever.** A "GH" ligature set above the words GREAT HAUSES makes
  the reader parse the same two letters twice. The crest is the mark.
